
# 网络模型设计

```
卷积层 -> 池化层 -> 归一层 -> 卷积层 -> 池化层 -> 归一层 -> 全局池化层 -> 全连接层-> 全连接层 ->  连接层
```

1. 卷积层  图片rgb 3通道的64 * 64输入，16通道输出。使用3 * 3的卷积核
2. 池化层  16通道的64 * 64数据压缩为16通道32 * 32 ， 步长为2
3. 归一层  
4. 卷积层  16通道的32 * 32数据输入 ， 32通道输出。同样使用3 * 3的卷积核
5. 池化层  32通道的32 * 32数据压缩为16 * 16 ， 步长为2
6. 归一层
7. 全局池化层  将每个通道的 16 * 16 使用平均池化压缩成1 * 1。这样相当于就是一个32维的向量了。
8. 全连接层  32维连接到64维
9. 全连接层  64维连接到32维
10. 全连接层  32维最后输出为3维，分别对应是某种颜色的概率

# 代码流程
1. 首先在引入训练数据集之后，对其进行数据加强。包括翻转，旋转，调亮度对比度
    ```python
        transforms.RandomHorizontalFlip(p=0.3),   # 将30%的图像水平翻转
        transforms.RandomRotation(10),         # 将图像随机旋转±10度
        transforms.ColorJitter(brightness=0.1, contrast=0.1, saturation=0.1),  # 随机调整亮度、对比度和饱和度
    ```
2. 设置损失函数和优化器、创建模型
- 交叉熵损失函数，Adam优化器，余弦退火
    ```python
        criterion = nn.CrossEntropyLoss() 
        optimizer = optim.Adam(net.parameters(), lr=LEARNING_RATE , weight_decay=1e-4)
        scheduler = optim.lr_scheduler.CosineAnnealingWarmRestarts(optimizer, T_0=30, T_mult=2, eta_min=1e-5)  
    ```
3. 迭代训练模型
    1. 使用当前的神经网络计算得出结果
    2. 计算交叉熵损失
    3. 计算用于反向传播的梯度
    4. 根据梯度来更新模型参数
    ```python
        optimizer.zero_grad()  
        outputs = net(datas) 
        loss = criterion(outputs, labels) 
        loss.backward() 
        optimizer.step() 
    ```
    5. 评价模型训练结果并输出相关信息
        - 这一部分我没有使用test.py中写的评价函数，而是自己借助ai重新写的。
        - 原来的代码是只根据模型在测试集1的正确率来决定是否要保存模型。我把它改成了根据训练集和两个测试集的平均正确率来保存。因为我发现按照第一种逻辑时，有的时候测试集1有90+%时，测试集2才刚过60%，尽管这样它也保存了（有点米唐！？）。
