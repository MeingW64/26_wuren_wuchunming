## 作业二：手搓多元线性回归与正则化 (加州房价数据集)

**任务描述：** 手写多元线性回归类对加州房价数据集进行分析预测，随后引入正则化惩罚重新回归，分别输出为两个 `.ipynb` 文件。
    参考: https://www.heywhale.com/mw/project/688fc21847bda3f715a7ba5c

    我来手搓？真的假的？
    看了一下午的线性回归视频讲解，又去学了CAN牢师的矩阵求导，最后发现整个回归公式的代码并不是很难
    一开始只写了短短几行
```
    X = np.column_stack([np.ones(20640) , X])
    B = np.linalg.inv(X.T @ X) @ (X.T @ Y)
    Yhat = X @ B
    Q = Yhat - Y
```
后面发现要写成类，于是封装了一下(逃)第一问一开始用zscore把数据标准化了，然后发现这样每个特征值的均值都变成0了，在不带截矩的情况下，训练集的预测均值也变为0了，和原数据误差巨大。(决定系数达到了惊人的-2！回归，轻而易举阿！)。于是第二问就不考虑不带截矩的情况了
第二问选择加入L2正则化，在Q的后面加上了$|B|^2$，前面带一个正则化强度系数。由于直接加了$|B|^2 * E_n$,我们平等的惩罚了每一个特征。 
图像里面好多点都是真实值相同，预测值则大相径庭。这也是回归的一环吗？(汗)这是否意味着不同的特征造成的影响仍然很大？

## 作业三：调用 SVM 库进行 Iris 鸢尾花分类

**任务描述：** 调用 SVM 库对 iris 鸢尾花数据集进行分类。
任务参考：https://scikit-learn.cn/stable/modules/svm.html
这一问的代码是用ai跑的，使用了svm库里面的svc分类器。由于鸢尾花数据在4个特征上疑似有一定的非线性重叠部分，普通的线性核无法将其完全区分，因此使用的是RBF核。RBF核能够将数据映射到更高维空间上，使得原本线性不可分的区域变得线性可分，获得更高的分类准确率。同时，RBF核使用的参数也比较少，只有gamma和正则化系数c，调参更容易。
可视化部分中，为了画出决策平面，代码使用PCA方法将原特征空间降维。

## 作业四：K-Means 聚类算法补全

**任务描述：** 根据提供的初始 `.ipynb` 文件和数据集，尝试完成 K-Means 聚类算法。

    花了好一会来看给出的代码。
    自己手搓的时候感觉对每个部分的列表,ndarray有点分不清。对ndarray的维数也很难理清。每一个函数之间的联动关系也看了挺久
    k-means的思想非常简单，但又非常巧妙。先人为设置几个中心，然后自动将离中心近的点归到同一类下，如此反复迭代，直到中心不再变化。
    显然，K的值不能一直增大(我说每个点都是一类才是最优解有没有懂的)。当cost随K的变化率下降到一定程度时，我们就应该认为K已经找到最优值了。
    跑图时也发现有时会有单点成簇的情况。这个点初始被设为中心，但所有其他的点离其他中心的距离都比离这个点近，所以这个中心不会随迭代而变动。
